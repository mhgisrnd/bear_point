# 지도 회전과 내 위치 표시

- 두 손가락으로 지도를 회전할 수 있습니다. 데스크톱에서는 Alt+Shift를 누른 채 마우스로 드래그합니다.
- 산 아이콘은 기존 지리산 초기 위치·배율 이동과 함께 회전 각도를 0으로 초기화합니다. 진행 중인 카메라 애니메이션은 먼저 취소합니다.
- 수동 관측점의 방향 핸들 터치 판정은 지도 좌표를 화면 좌표로 변환해 계산합니다. 지도를 회전해도 표시된 핸들을 그대로 조작할 수 있습니다.
- 두 손가락 또는 Alt+Shift 회전 중에는 수동 좌표·방위 드래그를 시작하거나 계속하지 않습니다.
- 내 위치는 기존의 48px 점·방향 화살표 형태를 사용합니다. 화살표에 흰 테두리와 짙은 윤곽선을 넣고 원과의 간격을 확보해 분리해 보이도록 합니다. 위치 점의 중심을 아이콘 회전 기준점으로 맞춰 간격 변경으로 GPS 표시 위치가 움직이지 않도록 했습니다. 지도 마커 옆 방위각 숫자는 표시하지 않으며, 등록 팝업의 방향각 표시를 사용합니다. 위치 레이어는 다른 지도 도형 위에 그리며 관측점 아이콘과 GPS 좌표 계산은 변경하지 않습니다.

검증: 실제 브라우저의 두 손가락 터치 회전, 데스크톱 회전, 산 버튼의 각도·중심 복구, 회전 후 방향 핸들 조작, 등록 중 두 손가락 회전 시 좌표 유지, 온라인·오프라인 초기화와 배경지도 선택을 확인했습니다. 위치 표시는 브라우저에서 서울 좌표를 지정해 검증했으며 실제 기기의 GPS 센서 측정값을 사용한 테스트는 아닙니다.


## 상세 팝업 높이 보정 (2026-11-05)

관측점·개체 상세 팝업은 패널의 실제 화면 교차 영역을 확인해 위·아래·좌·우 공간을 선택한다. 패널이 전체 화면을 차지하거나 전환 중이라 본문을 읽을 공간이 없으면, 보이는 지도 영역을 기준으로 배치하고 본문을 스크롤한다. 화면 밖 패널 때문에 최대 높이가 0px이 되는 현상을 방지한다. 닫기 버튼은 본문 스크롤 밖에 유지한다.

검증: 패널이 화면 전체를 덮는 조건에서 기존 최대 높이 0px 문제를 회귀 테스트로 재현한 뒤 수정했다. 관련 Node 테스트 17개를 통과했다. 실제 Chrome에서 320×740, 390×844, 844×390, 1180×820 크기로 온라인·오프라인 조건을 각각 확인했다. 관측점과 개체 팝업, 상세 펼침·본문 스크롤·지도 이동·화면 회전·패널 전체 펼침 후 복원을 검사했다. Android 네이티브 연동은 테스트용 응답을 사용했으며, 연결된 실기기가 없어 실제 Android WebView 검증은 수행하지 않았다. 앱 버전 설정은 변경하지 않았다.
